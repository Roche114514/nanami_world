# 七海千秋 · 文字世界（nanami_world v0.5.7）

面向 **Shinsekai（>= 2.6.0）** 的独立像素风自定义文字世界插件。

对大语言模型来说，世界由语言构成；对人类来说，前端是一个可高度自定义调色板的俯视像素小屋。你只需输入一句话即可同时编译出**规范化的智能物件属性**与**透明底像素贴图**，把真实存在于账本中的物品摆进离散坐标格网里，让角色在物质守恒与物理边界内自主感知与互动。

## v0.5.7 更新

- **独立「挖除地块」与虚空地形**：建造工具栏新增 `🕳 挖除地块`（支持单格/拖拽挖空及 `Shift` 拖拽矩形挖空），支持在地图中雕刻异形房间与浮空地形；内置防卡死护栏（自动跳过角色所在格、同步清理格上物件与台地台阶、禁止在虚空摆放/寻路通行，且镐子拆除不会误恢复虚空）。
- **多色像素蓝图格式与 6 套内置调色盘**：升级造物像素格式至最多 62 色自由调色盘并保留手绘原始布局（完全向后兼容既有 6 色槽蓝图）；内置经典像素 32 色、人物肤色与发色、暖木星露谷、马卡龙柔粉、赛博霓虹、自然草木材质 6 组调色盘，支持自由取色、Hex 输入、已用色与最近使用色。
- **统一「像素工坊」画布（造物 + 角色皮肤）**：在「✨ 造物」新增 `🎨 像素画布手绘造物`，支持画笔/橡皮/填充/吸管/直线/矩形/对称镜像/洋葱皮/微移翻转/多帧编辑与 40 步撤销重做；并在「🎭 角色管理」与外观弹窗接入角色皮肤像素画布，支持三向绘制（左侧自动镜像）、从当前外观无损导入精修、素体草稿及四向实时行走预览。
- 观剧和电影镜头切换时，NPC 继续自主行动。聊天暂停需要附近的真实玩家发起漫游交谈。
- `WorldBridge` 新增 `set_dialogue_focus`，对接 [故事引擎](https://github.com/Roche114514/nanami_story) 的关键对话。对白播放后才向上层交付原话，上一幕结束时解除聚焦。
- 故事抉择优先于日常闲聊和结伴行动。搭话被拒时同步暂停跨空间寻人，进门后短暂驻留，减少闲逛和反复穿门。

## v0.5.5 更新

- **观剧视角升级与安全切房**：观剧模式支持**自由视角 / 观战视角（`follow`） / 电影视角（`cinema`，自动跟随当前对话或关键行动角色并跨建筑切换）**；修复观剧模式切换房间时误将房间内角色传出门外的问题。
- **独立「角色管理」面板**：支持在不进入世界的情况下配置角色像素皮肤/立牌外观，以及各世界（含 `__default__` 默认初始关系模板）的双向关系与情感态度指针，新世界自动继承对应外观与初始关系。
- **23:30 夜间默认归寝跳过夜晚**：到 `23:30` 默认全体角色上床并自动跳过夜间时间推进，仅保留具备明确夜间事务（`night_active`）的角色继续在夜里行动。
- **座椅/卡座沙发与床铺语义分离**：长椅、座椅及咖啡厅/休息区靠窗卡座沙发统一归类为清醒坐姿 `rest_mode: "sit"`（保留懒人沙发、床铺与猫窝为 `sleep`），并允许来自上层高优抉择（`source="persona_choice"`）主动唤醒休息中的角色。
- **三层解耦社交净化与 `WorldBridge` 扩展**：全面过滤自主社交与对话中的内心独白、提示词泄漏并真实接入人格模型驱动；`WorldBridge` 协议扩展至 31 项 `SUPPORTED_OPS`（新增跨世界关系查询/初始化 `get_actor_relations` / `seed_initial_relations`、自由行动意图 `propose_actor_commitment`、氛围事件 `emit_ambient_cue`、天气时间设置 `set_world_environment` 与 `list_realms` 等）。

- **推门点亮与光影氛围渲染**：含内室门的室内启用基于洪水填充的推门点亮迷雾与平滑渐显，隐匿暗室 NPC 气泡与分区徽章；新增北墙 `glass_wall` 逐窗天色/天气窗景与斜向窗前光束、壁灯/炉灶/壁炉/台灯局部暖光圈、墙底踢脚线及墙脚 AO 投影。

## v0.4.0 更新

- **天气与作息**。城镇共享五种天气，天气会影响户外视野和热饮冷却。NPC 按人格生物钟和城镇设施安排日程。
- **饥饿与补货**。不同食物提供不同饱腹效果，营业场所每天模拟时间 06:00 自动补货。
- **主题小镇与扩建**。从一句描述生成主题小镇，在现有小镇加盖建筑，并验证广场、建筑入口和室内设施之间的通路。
- **结伴到场与汇合**。角色可以约好去建筑或同一张地图上的物件旁。先到的人等同伴，确认汇合后各自按约行动，等待超时后恢复自主活动。送同伴回住处时，送行者留在门外，另一人进屋休息。
- **休息时巩固情景记忆**。连续休息满 2 个模拟分钟后，角色把近期亲历的探索、活动和交往存为记忆及人物、场所印象。启用「使用世界经历」时，玩家对话和后台反思可以召回往事。认知面板可查看最近 3 条巩固记忆。

## v0.3.0 更新

- **城镇漫游**。创建樱町小镇，步行进入各个建筑。NPC 按昼夜、体力、可见物品和同伴关系自主行动。
- **主控交互**。按 `E` 与眼前门洞、物品或角色互动。NPC 当面打招呼时会打开对话框，等玩家输入回应。

- **NPC 随身物品与赠礼**。NPC 可以使用背包与自己的箱子，并按人格、物品偏好和关系决定是否收礼或送礼。主控可接受或谢绝 NPC 送来的礼物。
- **运行修复**。减少 Windows 后台终端闪窗、频繁进出同一扇门和对话整轮复读。夜间约好送同伴回住处时，告别后会继续执行进屋休息的计划。

## 核心特性

1. **「以文生像素」造物（零显存 / 零 VLM）**：输入一句话（如「桌角一杯冒着热气的抹茶」），复用宿主纯文本大模型一次产出智能物件规范与受限 7 色槽像素矩阵，并配备页内 16×16 像素微调画笔，也支持上传外部静态 PNG 立牌/贴图覆盖皮肤。
2. **严格物质守恒**：内置 10 件默认像素贴图仅作素材蓝图；只有被用户放进空间的物体才写入世界账本 `world.json`。消耗品归零即空或消失，闭合容器内的物品脱离角色视野，LLM 无法编造或操作账本外的道具。
3. **10 个正交智能物件组件 + 4 个统一工具**：`portable` / `surface` / `container` / `consumable` / `thermal` / `switchable` / `restable` / `activity` / `inscribable` / `portal` 自动推导出此刻合法动词，配合 `world_act` / `world_move` / `world_write` / `world_combine` 安全交互。
4. **明确离散坐标空间与静态角色导入**：支持一键扫描 `data/config/characters.yaml` 导入宿主角色或新建自定义角色，采用单帧静态贴图按脚底坐标 `(x, y)` 精确落格与 Y-sort 遮挡排序（不做复杂骨骼动画），配合 BFS 连通寻路与多空间门拓扑拓展。
5. **双视界切换与高度自定义调色板**：内置 5 套像素色板预设与色块/Hex 导入导出；点顶部「👁 她的视角」一键在像素小屋与复古文字终端间切换。
6. **两级离线心跳 & 与 `nanami_persona` 零耦合联动**：0-Token 物理时钟推进昼夜、降温与作息；若同时安装了 `nanami_persona`，自动只读感知 `mind.json` 与 `traits.json` 并导出 `bridge/<actor_id>.json`。

## 体验共同解谜

1. 在同一房间放入两位角色、一枚「黄铜旧钥匙」和一个「带锁木宝箱」。选中一位角色，让对方通过钥匙的「拿起」按钮持有钥匙。
2. 切换到另一位角色，选中宝箱并点「请某某帮忙开锁」。同伴会根据当前状态接受或婉拒。开锁成功后，可以问两位角色「还记得上次开的箱子吗？」。
3. 回到同一个房间，再放一个带锁木宝箱。让上次发起合作的角色执行「自主行动」。如果同伴还持有适配的钥匙，角色在探索时可以根据上一次的经历再次发出邀请。

设置页的「使用世界经历」控制历史经历是否参与回忆和自主行动。共同解谜记录按世界和参与角色检索。安装人格模型并绑定角色后，两人还会对同一结果分别产生心境反馈。

## 复现验证

在 Shinsekai 安装目录运行以下命令。示例检出路径为 `github/nanami_world`，检出到其他位置时请替换为实际路径。若仓库位于安装目录之外，将环境变量 `SHINSEKAI_TEST_ROOT` 指向包含 `sdk` 的 Shinsekai 安装目录。人格回写集成测试还需要 Node.js 和已安装的 `nanami_persona`。

```text
python -B -m unittest discover -s github/nanami_world/tests -p "test_nanami_*.py" -v
node --test github/nanami_world/tests/*.cjs
python -B github/nanami_world/tests/experiment_nanami_town.py
```

视野实验使用隔离存档和离线规则比较现有投影与遮挡原型。

## 安装与启用

1. 从 Shinsekai 插件市场安装，或将仓库放入 `plugins/nanami_world/`。
2. 在 `data/config/plugins.yaml` 中启用：

```yaml
- entry: plugins.nanami_world.plugin:NanamiWorldPlugin
  enabled: true
```

重启 Shinsekai 后，可在聊天工具条点击 **「文字世界」** 按钮（或进入工具/设置页）打开画布。

## 数据隔离说明

所有用户创造的空间、蓝图、调色板、上传贴图与事件流均保存在独立数据目录 `data/plugins/community.nanami.world/` 下；升级或重新安装插件不会覆盖任何世界数据。
